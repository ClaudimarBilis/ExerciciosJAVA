# Java - Exercícios e Fundamentos

Repositório dedicado ao estudo e à prática de programação em Java.

Este projeto reúne exercícios desenvolvidos durante minha jornada de aprendizado, com foco na construção de uma base sólida em lógica de programação, sintaxe Java e resolução de problemas.

Não é apenas uma coleção de exercícios, é um registro público da minha evolução como desenvolvedor Java.

## Objetivo

O objetivo deste repositório é registrar minha evolução no aprendizado de Java por meio da prática constante e da resolução progressiva de exercícios.

Além de servir como material de estudo e consulta, o repositório também funciona como um histórico do meu desenvolvimento técnico.

## Conteúdos estudados

Os exercícios são organizados progressivamente de acordo com os conceitos estudados.

### Nível 1 — Variáveis e entrada de dados

- Declaração e utilização de variáveis
- Tipos primitivos
- String
- Scanner
- Entrada de dados pelo console
- Operações matemáticas básicas

### Nível 2 — Estruturas condicionais

- if
- else
- else if
- Operadores relacionais
- Operadores lógicos
- Validação de dados
- &&
- ||
- %

### Nível 3 — Estrutura `switch`

- switch
- case
- default
- switch expression
- break
- Tomada de decisão baseada em múltiplas opções

### Nível 4 — Estruturas de repetição

- for
- while
- Contadores
- Acumuladores
- break
- Repetição controlada por condições
- Processamento de múltiplos valores

### Nível 5 — Problemas práticos

Exercícios voltados à aplicação dos conceitos estudados em situações mais próximas de problemas reais de programação.
