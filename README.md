# Java - Exercícios e Fundamentos

Repositório dedicado ao estudo e à prática de programação em Java.

Este projeto reúne exercícios desenvolvidos durante minha jornada de aprendizado, com foco na construção de uma base sólida em lógica de programação, sintaxe Java e resolução de problemas.

Não é apenas uma coleção de exercícios, é um registro público da minha evolução como desenvolvedor Java.

## Objetivo

O objetivo deste repositório é registrar minha evolução no aprendizado de Java por meio da prática constante e da resolução progressiva de exercícios.

Além de servir como material de estudo e consulta, o repositório também funciona como um histórico do meu desenvolvimento técnico.

## Metodologia

Cada programa é desenvolvido de forma incremental.

O processo de desenvolvimento envolve:

1. Análise do problema
2. Definição da lógica
3. Implementação
4. Testes
5. Identificação de erros
6. Refatoração
7. Evolução do programa

O objetivo é desenvolver não apenas conhecimento da linguagem Java, mas também capacidade de pensar, estruturar e implementar soluções.
