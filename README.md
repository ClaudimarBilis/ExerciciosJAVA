## Sobre o projeto

Estou utilizando este repositório para transformar conhecimento teórico em **prática constante**.

Os exercícios são desenvolvidos de forma progressiva: começo com conceitos fundamentais da linguagem e aumento gradualmente a complexidade das soluções.

A proposta é que os primeiros programas representem minha construção da base e que, conforme novos conceitos sejam aprendidos, os projetos antigos possam ser **refatorados e evoluídos**.

### Objetivos

* Desenvolver uma base sólida em Java
* Aprimorar lógica de programação
* Praticar resolução de problemas
* Aprender a estruturar e organizar código
* Desenvolver aplicações cada vez mais próximas de cenários reais
* Construir uma base para desenvolvimento backend com Java

# Como estudo

Cada exercício é desenvolvido seguindo um processo incremental:

```text
1. Entender o problema
       ↓
2. Definir a lógica
       ↓
3. Implementar
       ↓
4. Executar e testar
       ↓
5. Identificar erros
       ↓
6. Corrigir
       ↓
7. Refatorar
       ↓
8. Aplicar o conhecimento em problemas maiores
```

Mais do que memorizar sintaxe, o objetivo é desenvolver a capacidade de **entender um problema, construir uma solução e melhorar o código ao longo do tempo**.
